# [초등] 내 드론에게 생각하는 힘을! — AI 드론 탐험대

> 대상: 초등학생 (기준: **3~6학년**, 아래 "수준 조절 팁"에서 저학년·고학년 조정) · 120분 · 기본 1인 1대
> 공통 사항(교구 가정, 안전 수칙, 운영 방식)은 `00_공통_기획개요.md`를 참고하세요.

---

## 1. 수업 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 질문 | **"드론은 어떻게 알고 움직일까?"** |
| 핵심 개념 | AI는 **보고(감지) → 생각하고(판단) → 움직인다(행동)**. 센서는 AI의 눈이다. |
| 코딩 개념 | 순서대로 하기(순차), **만약 ~라면(조건)**, 여러 번 하기(반복) |
| 최종 미션 | 🚁 **색깔 신호 구조 드론**: 색깔을 보고 스스로 판단해 행동하는 드론 만들기 |
| 산출물 | 미션 성공 도장판, "AI 드론 탐험대" 3줄 소감 |

## 2. 학습 목표

1. AI가 **감지 → 판단 → 행동**의 순서로 움직인다는 것을 설명할 수 있다.
2. 블록코딩으로 드론을 **순서대로** 비행시키고, 도트 매트릭스에 그림을 나타낼 수 있다.
3. **"만약 ~라면"** 블록으로 센서가 감지한 색깔에 따라 다르게 행동하는 드론을 만들 수 있다.
4. 드론 안전 수칙을 지키며 친구와 함께 활동할 수 있다.

## 4. 단계별 상세

### 4-1. 도입 (0~10분) — "드론이 어떻게 알았을까?"

- **강사 시연:** 미리 코딩한 드론이 이륙합니다. 빨강 카드를 보면 😢 표시 후 착륙하고, 초록 카드를 보면 😊 표시 후 앞으로 날아갑니다.
- **발문 예시**
  - "선생님이 리모컨으로 조종했을까요? 아니면 드론이 스스로 알았을까요?"
  - "드론은 무엇으로 색깔을 '봤을까요'?"
  - "오늘 여러분은 **스스로 생각하는 드론**을 만드는 AI 개발자가 됩니다!"

### 4-2. 언플러그드: 사람 드론 게임 (10~25분)

**준비:** 색 카드, 바닥 테이프 칸 (또는 교실 통로)

| 단계 | 방법 | 깨닫는 것 |
|---|---|---|
| **1단계: 명령대로 움직이는 드론** (5분) | 짝 중 한 명은 "드론", 한 명은 "코더". 코더가 "앞으로 2칸 → 오른쪽 돌기 → 앞으로 1칸"을 미리 종이에 써서 주면, 드론 역할은 **눈을 감고** 그대로 움직입니다. | 순서대로 명령하기 = **코딩**. 하지만 앞에 의자가 있으면? 부딪혀요! |
| **2단계: 보고 생각하는 드론** (7분) | 이번엔 드론 역할이 **눈을 뜹니다**(센서 켜기!). 규칙: "**만약** 빨간 카드가 보이면 멈추고, **만약** 초록 카드가 보이면 앞으로 가기." 강사가 카드를 들어 보입니다. | 눈(센서)으로 **보고 → 규칙으로 생각하고 → 움직이기** = AI |
| **정리** (3분) | 칠판에 그림으로 정리 | 👀 감지(센서) → 🧠 판단(코드) → 🦵 행동(모터) |

- **발문:** "1단계 드론과 2단계 드론 중 누가 더 똑똑했나요? 왜 그럴까요?"

### 4-3. 안전 약속 & 드론 탐색 (25~35분)

- **안전 약속 따라 말하기:** 공통 수칙 8가지 중 초등 핵심 5가지
  1. "비행 구역 안으로 들어가지 않아요!"
  2. "프로펠러가 돌 땐 손대지 않아요!"
  3. "얼굴 쪽으로 날리지 않아요!"
  4. "이상하면 **긴급 정지!**"
  5. "떨어지면 멈춘 뒤에 주워요!"
- 🔍 **드론 몸속 센서 찾기:** 드론을 직접 살펴보며 활동지 그림에 표시합니다.
  - 👀 눈 = 색깔 센서, 적외선 센서 / 🖥️ 얼굴 = 도트 매트릭스 / 🦵 다리 = 모터와 프로펠러 / 🔋 심장 = 배터리
- **긴급 정지 실습:** 프로펠러가 돌기 시작하면 바로 긴급 정지를 눌러 봅니다. (모두 1회)

### 4-4. 첫 비행 코딩 (35~55분) — 순차

> ⚠️ 블록 이름은 실제 이글 코딩 앱에 맞춰 수정 예정입니다.

**도전 ① 첫 비행**
```
[시작하기]
[이륙하기]
[2초 기다리기]
[착륙하기]
```

**도전 ② 내 드론 얼굴 만들기**
```
[시작하기]
[도트 매트릭스에 😊 표시하기]
[이륙하기]
[앞으로 50cm 가기]
[착륙하기]
[도트 매트릭스에 ♥ 표시하기]
```

**도전 ③ (빨리 끝낸 학생)** 앞으로 갔다가 **돌아와서** 착륙하기 (회전 블록 사용)

- **운영 팁:** 자리에서 코딩 → 비행 구역에서 테스트 → 자리로 돌아와 수정. 1인당 **2~3회 테스트**를 목표로 합니다.
- **발문:** "블록 순서를 바꾸면 어떻게 될까요?" (예: 착륙을 이륙보다 먼저 두기)

### 4-5. 쉬는 시간 (55~65분)

- 배터리를 교체합니다. 강사는 배터리 상태와 프로펠러 가드를 점검합니다.

### 4-6. 생각하는 드론 만들기 (65~85분) — 조건

**도전 ④ 색깔을 보면 표정이 바뀌는 드론** (비행 없이 먼저 → 안전하고 빠르게 성공)
```
[시작하기]
[계속 반복하기]
    [만약 < 색깔 센서 = 빨강 > 이라면]
        [도트 매트릭스에 😢 표시하기]
    [만약 < 색깔 센서 = 초록 > 이라면]
        [도트 매트릭스에 😊 표시하기]
```
- 색 카드를 센서에 대 보며 표정이 바뀌는지 확인합니다. → **"이게 바로 감지 → 판단 → 행동이에요!"**
- ⚠️ 색상 센서가 **아래쪽**이면 드론을 색 카드 위에 올려놓고, **앞쪽**이면 카드를 앞에 보여 줍니다.

**도전 ⑤ 앞에 무언가 있으면 멈추는 드론** (적외선 센서)
```
[시작하기]
[이륙하기]
[계속 반복하기]
    [만약 < 앞에 물체가 있다 > 이라면]
        [도트 매트릭스에 ⚠ 표시하기]
        [착륙하기]
    [아니면]
        [앞으로 조금 가기]
```
- 강사나 친구가 **상자(장애물)**를 들고 서 있으면 드론이 멈추는지 확인합니다. 손은 쓰지 않습니다.
- ⚠️ 적외선 센서의 실제 감지 방식(거리 값 / 있음·없음)에 맞춰 블록을 수정합니다.

### 4-7. 최종 미션: 색깔 신호 구조 드론 (85~110분)

> **상황:** "산에서 길을 잃은 사람을 찾는 구조 드론이에요. 바닥의 색깔 신호를 보고 스스로 판단해야 해요!"

**미션 판 예시 (비행 구역 안)**
```
 [출발] ──→ [초록 카드: 계속 가!] ──→ [빨강 카드: 구조자 발견! 착륙]
```

| 단계 | 도전 내용 | 도장 |
|---|---|---|
| ⭐ 1단계 | 출발해서 **빨강 카드 위에 가면** 😢를 띄우고 착륙하기 | 🥉 |
| ⭐⭐ 2단계 | **초록이면 계속 앞으로**, 빨강이면 착륙하는 드론 | 🥈 |
| ⭐⭐⭐ 3단계 | 빨강 = 착륙, 초록 = 앞으로, **파랑 = 오른쪽으로 돌기**. 강사가 카드 배치를 바꿔도 성공하기 | 🥇 |
| 🏆 보너스 | 구조에 성공하면 도트 매트릭스에 "SOS" 또는 ♥ 애니메이션 띄우기 | 🏅 |

- **핵심 포인트:** 3단계에서 강사가 카드 위치를 **바꿉니다** → "드론이 길을 외운 게 아니라 **보고 판단한 거예요!**"
- 실패한 학생에게: "드론이 무엇을 잘못 봤을까? 어떤 규칙을 고치면 될까?" → 디버깅 칭찬

### 4-8. 정리 (110~120분)

- **생활 속 AI 찾기 OX 퀴즈:**
  - 자동문이 사람을 보고 열린다 → 감지는 하지만 아주 단순한 기계예요.
  - 로봇청소기가 벽을 피한다 → 오늘 만든 드론과 같아요!
  - 스마트폰이 내 얼굴을 알아본다 → 더 똑똑한 AI예요.
- **AI도 실수할 수 있어요:** "교실이 어두우면 색깔을 잘못 볼 수도 있어요. 그래서 AI를 만드는 사람은 **확인하고 고치는 것**이 중요해요."
- **출구 카드 (3줄 소감):** ① 오늘 드론에게 가르친 것 ② 어려웠던 점 ③ 내가 만들고 싶은 AI 드론

## 8. 선택형 AI 확장 — "손으로 명령하는 드론" (인터넷 가능 시, 15분)

- **넣는 위치:** 최종 미션 3단계를 생략하고 **95~110분**에 진행 (또는 고학년 반에서 언플러그드 2단계를 대체)
- **활동:**
  1. 티처블 머신(이미지 프로젝트)에 **✋ 보 = 이륙**, **✊ 주먹 = 착륙**, **아무것도 없음** 세 가지를 학습시킵니다. (강사 시연 또는 조별)
  2. 손을 보여 주면 AI가 맞히는지 확인합니다.
  3. AI가 "✋"라고 판단하면 → 학생이 **이륙 프로그램 실행**, "✊"라고 판단하면 → **착륙 프로그램 실행**
- **깨닫는 것:** "드론의 색깔 규칙은 **우리가 직접 만든 규칙**이고, 티처블 머신은 **사진을 보고 스스로 배운 규칙**이에요!"
- **AI 실수 체험:** 장갑을 끼거나 손을 멀리 두면 AI가 틀리는 것을 보여 주며 "AI는 **본 적 있는 것**만 잘 알아요."

## 9. 평가 체크리스트 (강사용)

| 평가 항목 | 상 | 중 | 하 |

| 문제 해결 | 실패 원인을 스스로 찾아 고침 | 도움을 받아 고침 | 다시 시도함 |
