## 1. 강의 개요

| 항목 | 내용 |
|---|---|
| 대상 | 초등학생 / 중학생 / 고등학생 **각각 별도 운영**(합반 아님), 학년은 학교급 안에서 폭넓게 |
| 시간 | 학교급별 **120분** (중간 쉬는 시간 10분 포함, 실제 수업 110분) |
| 교구 | 이글(Eagle) 코딩 센서 드론 (가이온 공급, WhalesBot Eagle 계열로 추정) |
| 운영 형태 | **기본: 1인 1대** / **플랜 B: 2~3인 1조 1대** |
| 수업 환경 | **A안: 일반 교실 + 태블릿** / **B안: 컴퓨터실 + PC** (둘 중 하나로 확정 예정) |
| 사전 경험 | 학교에서 배운 정도 (초: 엔트리·스크래치 기초 / 중·고: 정보 교과 수준) |
| AI 도구 | 기본은 **드론만 사용**, 인터넷이 될 때만 웹 AI 도구(티처블 머신) **선택형 확장** |

### 강의 전체를 관통하는 핵심 메시지

> **"AI는 '감지하고 → 판단하고 → 행동하는' 기계다. 드론의 센서는 AI의 눈, 코드는 AI의 생각, 모터는 AI의 몸이다."**

세 학교급 모두 이 틀(**감지 → 판단 → 행동**)을 공통으로 쓰고, 학교급이 올라갈수록 **판단**을 더 깊게 다룹니다.

- **초등:** 판단 = "만약 ~라면" 규칙
- **중등:** 판단 = 데이터를 보고 정한 기준값(분류)
- **고등:** 판단 = 오차를 고려해 설계하고 평가하는 의사결정 시스템

## 2. 교구 가정 및 확인 필요 사항

교구 판매 페이지에 접속하지 못해, 공개 기사와 제품 소개 영상을 바탕으로 아래와 같이 **가정하고 설계**했습니다.
**⚠️ 표시 항목**은 교구를 받거나 판매처에 문의한 뒤 확정해 주세요. 확정 결과에 따라 해당 활동을 고칩니다.

| 항목 | 기획안에서의 가정 | 근거 | 영향받는 부분 |
|---|---|---|---|
| 제조·공급 | WhalesBot Eagle 계열, 국내는 가이온 공급 | 공개 기사 | — |
| 판매가 | 드론 본체 **249,000원** (드론몰 기준) | 드론몰 상품 정보 | 예산 |
| 별도 판매 부품 | **이글드론 센서(39,800원)**, 배터리(28,000원), 프로펠러 가드 | 드론몰 이글드론 카테고리 | 준비물, 예산 |
| ⚠️ 센서 포함 여부 | 센서가 별도 판매 상품으로 올라와 있음 → **본체에 센서가 들어 있는지, 센서 모듈을 따로 사야 하는지** 확인 필요. 이 기획안은 **센서를 쓸 수 있다는 전제**로 설계 | 드론몰 상품 목록 | 전 학교급 후반부(65분 이후) 센서 활동 전체 |
| 센서 | **적외선 센서, RGB(색상) 센서, 도트 매트릭스(표시창)** | 제품 소개 영상 | 전 학교급 핵심 활동 |
| 코딩 기기 | 태블릿·스마트폰·PC에서 코딩 가능 | 공급사 소개 자료 | 환경 A·B안 |
| ⚠️ 코딩 환경 | **블록코딩 전용 앱/프로그램** (앱 이름 미확인) | 미확인 | 전 학교급 블록 예시 |
| ⚠️ 파이썬 지원 | 지원 여부 미확인 → 고등은 **블록 + 의사코드**를 기본으로 하고, 파이썬이 되면 전환 | 미확인 | 고등 기획안 |
| ⚠️ 센서 값 확인 | 센서 값을 **숫자로 화면에 띄워 볼 수 있다**고 가정 | 미확인 | 중·고 "데이터 측정" 활동 |
| ⚠️ 색상 센서 방향 | 아래쪽(바닥 색 카드 인식)과 앞쪽(색 카드를 보여주기) **두 경우를 모두 설계** | 미확인 | 색 인식 미션 |
| ⚠️ 적외선 센서 용도 | 앞쪽 **장애물 감지** 용도로 가정 | 미확인 | 장애물 미션 |
| ⚠️ 카메라 | **없다**고 가정 (카메라 없이도 되는 설계) | 미확인 | — |
| ⚠️ 비행시간 / 충전시간 | 배터리 1개당 **약 5~7분 비행**, 충전 40~60분으로 가정 | 일반적인 교육용 소형 드론 기준 | 배터리 운영 계획 |
| ⚠️ 동시 연결 | 여러 대를 동시에 연결해도 **간섭이 없다**고 가정 | 미확인 | 1인 1대 운영 |
| ⚠️ 프로펠러 가드 | 별도 판매 상품이 있음 → **기본 구성에 들어 있는지 확인**. 없으면 대수만큼 구매 필요 (안전 수칙상 필수) | 드론몰 상품 목록 | 안전, 예산 |
| ⚠️ 외부 프로그램 연동 | 티처블 머신 결과로 드론을 **직접 제어할 수 없다**고 가정 → 사람이 결과를 보고 드론 프로그램을 실행 | 미확인 | 선택형 AI 확장 |

## 3. 학교급별 설계 방향 (수준 위계)

| 구분 | 초등 | 중등 | 고등 |
|---|---|---|---|
| **핵심 질문** | "드론은 어떻게 알고 움직일까?" | "기계는 어떻게 구별할까?" | "믿을 수 있는 자율 시스템은 어떻게 설계할까?" |
| **AI 개념** | AI = 감지·판단·행동, 센서 = AI의 눈 | 데이터 → 기준 → 분류, 규칙 기반 vs 학습 기반 AI | 인지·판단·제어 흐름, 센서 오차, 의사결정 트리, 성능 평가 |
| **코딩 개념** | 순차, 조건(만약 ~라면), 반복 | 조건·반복·변수, 센서 값 활용 | 함수(모듈화), 다중 조건, 변수, (가능하면 파이썬) |
| **데이터 활동** | 색깔 보고 맞히기 (감각적) | 센서 값을 재서 기록하고 기준값 정하기 | 반복 측정으로 평균·범위를 구하고 여유값 정하기 |
| **최종 미션** | 색깔 신호 구조 드론 | 자율 배달 드론 | 재난 수색 자율 드론 (설계 → 구현 → 평가 → 개선) |
| **윤리·사회** | 안전 약속, AI도 실수할 수 있어요 | 드론과 사생활, 사고가 나면 누구 책임? | 자율 시스템의 책임 소재, 규제, AI·드론 진로 |
| **산출물** | 미션 성공 기록 + 3줄 소감 | 센서 측정표 + 알고리즘 순서도 | 설계서(의사결정 트리) + 성능 평가표 + 발표 |

> 교육과정 연계: 초등 실과(소프트웨어·로봇), 중학교 정보(인공지능·알고리즘과 프로그래밍), 고등학교 정보 및 인공지능 관련 선택과목과 연계됩니다. 학교 제출용 문서를 만들 때 해당 학년의 **성취기준 코드를 확인해 추가**할 예정입니다.

## 4. 공통 수업 흐름 (120분)

```
[도입 10분] → [AI 개념 · 언플러그드 15분] → [안전교육 · 드론 탐색 10분] → [기본 비행 코딩 20분]
      → [쉬는 시간 10분 · 배터리 교체] →
[센서 · AI 활동 15~20분] → [최종 미션 25분] → [공유 · 윤리 · 정리 10~15분]
```

- 쉬는 시간을 **배터리 교체 시간**으로 함께 씁니다.
- 앞쪽 60분은 "**드론과 친해지기 + 개념**", 뒤쪽 60분은 "**센서로 판단하는 AI 드론 만들기**"입니다.

## 5. 운영 모델

### 5-1. 기본: 1인 1대

1인 1대여도 **교실 안에서 20대 이상이 동시에 날 수는 없습니다.** 그래서 아래 방식으로 운영합니다.

> **"코딩은 자리에서, 비행은 비행 구역에서 순서대로"**

| 항목 | A안: 일반 교실 + 태블릿 | B안: 컴퓨터실 + PC |
|---|---|---|
| 비행 구역 | 책상을 벽 쪽으로 밀고 교실 가운데에 **2m × 2m 구역 4~6개** (마스킹 테이프) | 교실 뒤편이나 앞 공간에 **구역 2~4개**, 가능하면 옆 빈 교실도 사용 |
| 코딩 → 비행 | 태블릿과 드론을 들고 구역으로 이동해 바로 실행 | PC에서 코딩 → 드론 연결 → 구역에서 실행 (⚠️ PC 블루투스나 동글 필요 여부 확인) |
| 테스트 규칙 | 구역별 대기 줄, **1회 테스트 1~2분**, 끝나면 다음 사람 | 구역이 적으므로 **"테스트 번호표"**로 순서 관리 |
| 장점 | 이동이 짧아 테스트를 자주 할 수 있음 | 화면이 커서 코드 읽기와 수정이 편함 |
| 주의 | 책상 이동 시간이 필요 → **수업 전에 미리 배치** | 구역이 적어 기다리는 시간이 길어짐 → 기다리는 동안 할 **활동지 과제** 준비 |

- **배터리:** 드론 1대당 배터리 **2~3개** 권장, 충전 스테이션 1곳에서 관리 (⚠️ 실제 비행시간 확인 후 조정)
- **보조 인력:** 학생 20명이 넘으면 보조강사(또는 담임교사) **1명 이상** 권장. 비행 구역 안전 관리를 맡습니다.

### 5-2. 플랜 B: 2~3인 1조 1대

| 역할 | 하는 일 |
|---|---|
| 🧑‍💻 코더 | 태블릿·PC로 블록을 조립하고 수정 |
| 🧑‍✈️ 파일럿 겸 안전요원 | 드론을 비행 구역에 놓고 실행, **긴급 정지 담당**, 구역 주변 안전 확인 |
| 📝 기록 겸 디버거 | 결과 기록, "왜 실패했는지" 찾기, 활동지 작성 (3인 조일 때) |

- **역할 교대:** 활동이 바뀔 때마다 역할을 돌려서 **모두가 코딩을 한 번 이상** 하게 합니다.
- **시간 운영:** 드론 수가 줄어 테스트 대기 시간이 짧아지므로, 아낀 시간은 **미션 난이도 올리기**와 **조별 발표**에 씁니다.
- **평가:** 개인 평가 대신 **조별 미션 결과 + 개인 역할 수행 관찰**로 바꿉니다.
- 학교급별 기획안마다 **"플랜 B로 바꿀 때"** 항목을 따로 두었습니다.

## 6. 공통 안전 수칙

수업 시작 시 **모든 학교급에서 반드시** 지도합니다. 초등은 따라 말하기, 중·고는 체크리스트 서명 방식으로 진행합니다.

1. **비행은 비행 구역 안에서만.** 구역 안에 사람이 들어가지 않습니다.
2. **긴급 정지 버튼부터 익힙니다.** 첫 비행 전에 긴급 정지를 실습합니다. (⚠️ 앱의 긴급 정지 기능 확인)
3. 프로펠러 가드를 끼운 상태에서만 비행합니다. 프로펠러가 돌 때는 **손을 대지 않습니다.**
4. 비행 높이는 **1.5m 이하**, 사람 얼굴 쪽으로 날리지 않습니다.
5. 긴 머리는 묶고, 목걸이처럼 늘어지는 물건은 정리합니다.
6. **배터리가 부풀었거나 뜨거우면 사용하지 않고** 강사에게 알립니다.
7. 드론이 떨어지면 **프로펠러가 멈춘 뒤에** 줍습니다.
8. 실내 교육용 비행만 합니다. 실외 비행은 하지 않습니다.

## 8. 선택형 AI 도구 확장 (공통 원칙)

- **언제:** 인터넷과 카메라가 되는 기기를 쓸 수 있을 때만 진행합니다. 못 쓰면 기본 활동만으로도 수업이 완결되도록 설계했습니다.
- **도구:** 구글 티처블 머신(Teachable Machine). 로그인 없이 웹에서 이미지나 소리 분류 모델을 만들 수 있습니다.
- **드론과 연결하는 방법(가정):** 모델의 분류 결과(예: "✊ = 착륙", "✋ = 이륙")를 보고 **학생이 그에 맞는 드론 프로그램을 실행**합니다. 사람이 AI의 판단을 행동으로 옮겨 주는 셈입니다.
  ⚠️ 이글 코딩 환경이 외부 AI 모델과 직접 연동되는지 확인되면 자동 연동으로 바꿉니다.
- **핵심 학습 포인트:** 드론의 센서 판단은 **"사람이 규칙을 만든 AI"**, 티처블 머신은 **"예시를 보고 스스로 규칙을 배운 AI"**입니다. 두 방식을 비교해 봅니다.
