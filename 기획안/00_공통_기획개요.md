## 1. 강의 개요

| 항목 | 내용 |
|---|---|
| 대상 | 초등학생 / 중학생 / 고등학생 **각각 별도 운영**(합반 아님), 학년은 학교급 안에서 폭넓게 |
| 시간 | 학교급별 **120분** (중간 쉬는 시간 10분 포함, 실제 수업 110분) |
| 교구 | **이글(Eagle) 교육용 코딩 드론** (WhalesBot 제품, 국내 가이온 공급) |
| 학생용 구성 | 드론 기본 세트 + **LED 매트릭스** + **적외선 장애물 회피 센서** (1대당 각 1개) |
| 강사 시연용 | 위 구성 + **AI 이미지 모듈** 1~2개 (QR 코드·얼굴 인식) |
| 운영 형태 | **기본: 1인 1대** / **플랜 B: 2~3인 1조 1대** |
| 수업 환경 | **B안(기본): 컴퓨터실 + PC** / A안: 일반 교실 + 태블릿 (⚠️ 태블릿 앱 확인 필요, 없으면 노트북으로 대체) |
| 사전 경험 | 학교에서 배운 정도 (초: 엔트리·스크래치 기초 / 중·고: 정보 교과 수준) |
| 언어 | 초·중: **블록코딩** / 고: **블록 → 파이썬 전환** |
| 선택형 AI 도구 | 인터넷이 될 때만 웹 AI 도구(티처블 머신) 확장 |

### 강의 전체를 관통하는 핵심 메시지

> **"AI는 '감지하고 → 판단하고 → 행동하는' 기계다. 드론의 센서는 AI의 눈, 코드는 AI의 생각, 모터는 AI의 몸이다."**

세 학교급 모두 이 틀(**감지 → 판단 → 행동**)을 공통으로 쓰고, 학교급이 올라갈수록 **판단**을 더 깊게 다룹니다.

- **초등:** 판단 = "만약 ~라면" 규칙
- **중등:** 판단 = 데이터를 보고 정한 기준값
- **고등:** 판단 = 오차를 고려해 설계하고 평가하는 의사결정 시스템

### 교구 구성으로 보는 AI의 두 단계

| | 학생 드론 (적외선 장애물 센서) | 강사 시연 드론 (AI 이미지 모듈) |
|---|---|---|
| 무엇을 감지? | 앞에 물체가 **얼마나 가까운지** (숫자 값 1개) | 카메라 영상 속 **QR 코드, 얼굴** |
| 판단 방식 | **사람이 정한 규칙** ("값이 ○○보다 크면 장애물") | **데이터로 학습한 인식 모델**이 판단 |
| 수업에서의 역할 | 학생이 직접 규칙을 만들어 보는 **규칙 기반 AI** | "더 똑똑한 AI 눈"을 보여 주는 **학습 기반 AI 시연** |

→ 이 대비를 세 학교급 모두에서 활용합니다. (초: "더 많은 걸 알아보는 AI", 중: 규칙 기반 vs 학습 기반, 고: 신뢰성과 설명 가능성 비교)

### 2-2. 사양 이미지의 코드에서 확인한 함수 이름 (파이썬)

```python
from whalesbot import *
display_symbol(P1, 52)        # LED 매트릭스(포트 P1)에 기호 표시
fly_unlock()                  # 모터 잠금 해제
fly_start(100)                # 이륙 (높이 100cm)
fly_moveto(UP, 10)            # 방향(UP/DOWN/FORWARD?/BACK/LEFT/RIGHT) + 거리(cm)
get_gesture(P2)               # 제스처 센서(포트 P2) 값 읽기
DebugValue(1, var_Hand)       # 디버그 값 출력
battery()                     # 배터리 전압
fly_land()                    # 착륙
fly_lock()                    # 모터 잠금
```

블록 이름 예: `emotion screen symbols port`, `entering takeoff and landing mode`, `automatic takeoff height`, `fly backward 50 cm`, `gesture recognition port`, `battery voltage`

> 기획안의 코드 예시는 이 이름을 기준으로 썼습니다. 적외선 센서를 읽는 함수 이름 등 **이미지에 없는 이름은 ⚠️로 표시**했습니다.

### 2-3. 아직 확인이 필요한 사항

| 항목 | 기획안에서의 가정 | 영향받는 부분 |
|---|---|---|
| ⚠️ 태블릿 앱 | 사양 자료에는 PC 화면만 있음 → **PC(B안)를 기본**으로 설계 | 환경 A안 |
| ⚠️ 적외선 센서 값 | 아날로그 센서이므로 **숫자 값을 읽을 수 있다**고 가정 (가까울수록 값이 커진다고 가정 → 실제 방향 확인) | 중·고 데이터 활동 |
| ⚠️ 센서 장착 방향 | 적외선 센서를 **앞쪽**으로, LED 매트릭스를 **위·앞쪽**으로 동시에 장착할 수 있다고 가정 | 전 학교급 미션 |
| ⚠️ 동시 연결 | 블루투스 5.0으로 20대 이상이 한 공간에서 **혼동 없이 짝을 지을 수 있다**고 가정 → 드론·PC 번호 라벨로 관리 | 1인 1대 운영 |
| ⚠️ 긴급 정지 | 프로그램 화면의 **STOP 버튼**과 리모컨으로 긴급 정지할 수 있다고 가정 | 안전 |
| ⚠️ 독립 실행 시작 방법 | 내려받은 프로그램을 드론의 버튼이나 리모컨으로 시작한다고 가정 | 테스트 동선 |
| ⚠️ 내장 레이저 거리 센서 | 높이 유지용(아래쪽)으로 추정. 블록에서 값을 읽을 수 있으면 고등 비교 실험에 활용 | 고등 확장 활동 |
| ⚠️ AI 범주 블록 | 블록 메뉴에 "AI"가 있음 → AI 이미지·제스처 모듈 블록으로 추정 | 강사 시연 |
| ⚠️ 추가 모듈 가격 | 드론몰 "이글드론 센서" 39,800원 외에는 미확인 | 예산 |

## 3. 학교급별 설계 방향 (수준 위계)

| 구분 | 초등 | 중등 | 고등 |
|---|---|---|---|
| **핵심 질문** | "드론은 어떻게 알고 움직일까?" | "기계는 어떻게 판단 기준을 정할까?" | "믿을 수 있는 자율 시스템은 어떻게 설계할까?" |
| **AI 개념** | AI = 감지·판단·행동, 센서 = AI의 눈 | 데이터 → 기준값 → 판단, 규칙 기반 vs 학습 기반 AI | 인지·판단·제어 흐름, 센서 오차, 오탐·미탐, 성능 평가 |
| **코딩** | 블록: 순차, 조건(만약 ~라면), 반복 | 블록: 조건·반복·**변수**, 센서 값 비교 | 블록 → **파이썬**: 함수(My Blocks), 상태, 리스트 |
| **센서 활동** | 손이 가까이 오면 반응하는 드론 | 거리별 센서 값을 재서 **기준값 정하기** | 반복 측정, 장애물 재질별 측정 → **오차 범위와 여유값** |
| **최종 미션** | 🧭 동굴 탐험 구조 드론 | 📦 자율 배달 드론 | 🚨 재난 수색 자율 드론 (설계 → 구현 → 평가 → 개선) |
| **강사 AI 시연** | 얼굴을 알아보는 드론 | QR 주소를 읽는 배달 드론 | 얼굴·QR 인식 드론 → 신뢰성 토론 |
| **윤리·사회** | 안전 약속, AI도 실수할 수 있어요 | 사고가 나면 누구 책임?, 사생활 | 책임 소재, 규제, 설명 가능성, 진로 |
| **산출물** | 미션 도장판 + 3줄 소감 | 센서 측정표 + 순서도 | 설계서(상태 전이도) + 성능 평가표 + 발표 |

> 교육과정 연계: 초등 실과(소프트웨어·로봇), 중학교 정보(인공지능·알고리즘과 프로그래밍), 고등학교 정보 및 인공지능 관련 선택과목과 연계됩니다. 학교 제출용 문서를 만들 때 해당 학년의 **성취기준 코드를 확인해 추가**할 예정입니다.

## 4. 공통 수업 흐름 (120분)

```
[도입 10분] → [AI 개념 · 언플러그드 15분] → [안전교육 · 드론 탐색 10분] → [기본 비행 코딩 20분]
      → [쉬는 시간 10분 · 배터리 교체] →
[센서 · AI 활동 15~20분] → [최종 미션 25분] → [공유 · 윤리 · 정리 10~15분]
```

- 앞쪽 60분은 "**드론과 친해지기 + 개념**", 뒤쪽 60분은 "**센서로 판단하는 AI 드론 만들기**"입니다.
- **코딩 → 테스트 흐름:** PC에서 코딩 → 블루투스로 드론에 내려받기 → 드론을 비행 구역으로 가져가 실행 → 자리로 돌아와 수정

## 5. 운영 모델

### 5-1. 기본: 1인 1대

1인 1대여도 **교실 안에서 20대 이상이 동시에 날 수는 없습니다.** 그래서 아래 방식으로 운영합니다.

> **"코딩은 자리에서, 비행은 비행 구역에서 순서대로"**
> 프로그램을 드론에 내려받으면 PC 없이 실행되므로, **드론만 들고 비행 구역으로 이동**하면 됩니다.

| 항목 | B안(기본): 컴퓨터실 + PC | A안: 일반 교실 + 태블릿·노트북 |
|---|---|---|
| 비행 구역 | 교실 뒤편이나 앞 공간에 **2m × 2m 구역 2~4개**, 가능하면 옆 빈 교실도 사용 | 책상을 벽 쪽으로 밀고 교실 가운데에 **구역 4~6개** (마스킹 테이프) |
| 테스트 규칙 | 구역이 적으므로 **"테스트 번호표"**로 순서 관리, **1회 테스트 1~2분** | 구역별 대기 줄, 1회 테스트 1~2분 |
| 기다리는 동안 | 활동지 과제 (센서 측정표, 순서도, 디버깅 분석) | 같음 |
| 주의 | 구역이 적어 대기 시간이 김 → 미션 단계별로 **"자리에서 먼저 검증"**(비행 없이 센서·LED만 테스트) 과정을 넣음 | 책상 이동 시간이 필요 → **수업 전에 미리 배치** |

### 5-2. 배터리 운영 (비행 약 10분, 충전 40분, 기본 배터리 1개)

- 실제 비행은 1회 테스트에 30초~1분이므로, 1인당 수업 중 총 비행은 약 **8~12분**입니다. 연결과 대기에 쓰는 전력까지 생각하면 **배터리 1개로는 부족할 수 있습니다.**
- **권장: 드론 1대당 예비 배터리 1개 추가 구매** (총 2개) → 쉬는 시간에 교체
- **충전:** 배터리에 Type‑C 단자가 있으므로 **멀티포트 USB 충전기**(포트당 7.5W 이상)를 준비하고, 앞쪽 60분에 쓴 배터리를 바로 충전합니다.
- 수업 시작 전 **모든 배터리 완충**, 그리고 블록의 `battery voltage`로 **배터리가 부족하면 착륙**하는 안전 코드를 강사 템플릿에 기본으로 넣습니다.

### 5-3. 플랜 B: 2~3인 1조 1대

| 역할 | 하는 일 |
|---|---|
| 🧑‍💻 코더 | PC에서 블록을 조립·수정하고 드론에 내려받기 |
| 🧑‍✈️ 파일럿 겸 안전요원 | 드론을 비행 구역에서 실행, **긴급 정지(리모컨·STOP) 담당**, 구역 주변 안전 확인 |
| 📝 기록 겸 디버거 | 결과와 센서 값 기록, "왜 실패했는지" 찾기, 활동지 작성 (3인 조일 때) |

- **역할 교대:** 활동이 바뀔 때마다 역할을 돌려서 **모두가 코딩을 한 번 이상** 하게 합니다.
- **시간 운영:** 테스트 대기 시간이 짧아지므로, 아낀 시간은 **미션 난이도 올리기**와 **조별 발표**에 씁니다.
- **예산:** 드론·추가 모듈·예비 배터리가 1/2~1/3로 줄어듭니다.
- 학교급별 기획안마다 **"플랜 B로 바꿀 때"** 항목을 따로 두었습니다.

## 6. 공통 안전 수칙

수업 시작 시 **모든 학교급에서 반드시** 지도합니다. 초등은 따라 말하기, 중·고는 체크리스트 서명 방식으로 진행합니다.

1. **비행은 비행 구역 안에서만.** 구역 안에 사람이 들어가지 않습니다.
2. **긴급 정지부터 익힙니다.** 첫 비행 전에 STOP 버튼과 리모컨 정지를 실습합니다. (⚠️ 정확한 방법 확인)
3. 수업에서는 **풀 프로펠러 가드**(기본 구성품)를 끼운 상태에서만 비행합니다.
4. 비행 높이는 **1m 안팎**(`automatic takeoff height` 100cm 이하), 사람 얼굴 쪽으로 날리지 않습니다.
5. 긴 머리는 묶고, 목걸이처럼 늘어지는 물건은 정리합니다.
6. **배터리가 부풀었거나 뜨거우면 사용하지 않고** 강사에게 알립니다.
7. 드론이 떨어지면 **프로펠러가 멈춘 뒤에** 줍습니다. 프로펠러 교체는 강사가 **제거 도구**로 합니다.
8. 실내 교육용 비행만 합니다. (90g 소형 드론이지만 실외 비행은 하지 않습니다.)

## 8. 선택형 AI 도구 확장 (공통 원칙)

- **언제:** 인터넷과 카메라가 되는 기기를 쓸 수 있을 때만 진행합니다. 못 쓰면 기본 활동만으로도 수업이 완결되도록 설계했습니다.
- **도구:** 구글 티처블 머신(Teachable Machine). 로그인 없이 웹에서 이미지나 소리 분류 모델을 만들 수 있습니다.
- **드론과 연결하는 방법:** 모델의 분류 결과를 보고 **학생이 그에 맞는 드론 프로그램을 실행**합니다. 사람이 AI의 판단을 행동으로 옮겨 주는 방식입니다.
- **강사 AI 이미지 모듈 시연과의 관계:** 시연 모듈은 "**이미 학습된 모델**"을 쓰는 것이고, 티처블 머신은 "**모델을 직접 학습시켜 보는 것**"입니다. → 두 활동을 함께 하면 "학습 → 인식 → 행동"의 전체 흐름을 체험할 수 있습니다.
