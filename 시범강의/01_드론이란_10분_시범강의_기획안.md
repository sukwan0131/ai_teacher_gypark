# [시범강의] 드론이란? — 하늘을 나는 컴퓨터, 이제는 스스로 생각한다

> 문서 상태: **기획안 v0.1 (검토용)**
> 형식: 10분 시범강의 (담당자·심사위원 앞 시연) · 본 강의 **1차시 도입부**에 들어갈 내용
> 구성: **공통 뼈대 1개 + 학교급별(초·중·고) 조절표**
> 다음 단계: 이 기획안이 확정되면 슬라이드 제작

---

## 1. 강의 개요

| 항목 | 내용 |
|---|---|
| 주제 | 드론의 정의, 활용 사례, 드론을 배워야 하는 이유 |
| 시간 | **10분** (슬라이드 9장) |
| 형식 | 강사 설명 + 발문 + 실물 교구 보여 주기 (+ 선택: 10초 시범 비행) |
| 준비물 | 이글 드론 1대(풀 프로펠러 가드 장착), 슬라이드, 시범 비행 대비 백업 영상 |
| 본 강의와의 연결 | 마지막에 "**조종하는 드론 → 스스로 판단하는 드론(AI)**"으로 이어지며 본 수업(AI 드론 코딩)을 예고 |

### 핵심 메시지 (한 문장)

> **"드론은 '사람이 타지 않는 비행체'에서 시작해, 이제는 '스스로 보고 판단하는 하늘의 AI'로 진화하고 있다. 그래서 우리는 드론을 '조종'이 아니라 '코딩'으로 배운다."**

### 학습 목표

1. 드론의 뜻과 구성 요소를 설명할 수 있다.
2. 생활과 산업 속 드론 활용 사례를 3가지 이상 말할 수 있다.
3. 드론이 **원격 → 자동 → 자율**로 발전하고 있으며, 그 중심에 **AI**가 있음을 이해한다.

## 2. 심사 포인트를 고려한 설계 의도

심사위원 앞 시연이므로, 짧은 시간 안에 **수업 설계 역량**이 드러나도록 구성했습니다.

| 설계 의도 | 시연에서 보여 주는 방법 |
|---|---|
| **흥미 유발** | 첫 1분에 실물 드론 등장(무게 90g 손바닥 위) + 질문으로 시작 |
| **학생 참여** | 발문 3회, "이 드론은 무슨 일을 할까?" 사진 퀴즈 → 심사위원을 학생 삼아 짧게 진행 |
| **개념의 정확성** | 법령 정의(원격·자동·자율)를 근거로 제시 → 내용 신뢰도 |
| **본 수업과의 연결** | 법령의 "자율 = **인식·판단**" → AI 수업으로 자연스럽게 연결 |
| **학교급별 확장성** | 같은 슬라이드를 쓰되 설명 깊이와 예시만 바꾸는 **조절표** 제시 (4장) |
| **안전 의식** | 시범 비행 시 가드 장착, 비행 구역 확보를 말로 짚어 줌 |

## 4. 단계별 상세 (강의 대본 요약)

### 4-1. 도입 (0:00~1:00) — 슬라이드 1·2

- **행동:** 이글 드론을 손바닥 위에 올려 보여 줍니다.
- **멘트:** "이 드론의 무게는 90g, 달걀 두 개 정도예요. 이렇게 작은 비행체가 오늘 수업의 주인공입니다."
- **발문 ①:** "'드론' 하면 무엇이 떠오르나요?" → 예상 답: 촬영, 택배, 장난감, 전쟁, 드론 쇼
- **(선택) 10초 시범 비행:** 이륙 → 제자리 비행 → 착륙. 공간이나 상황이 맞지 않으면 **백업 영상**으로 대체
  - 안전 멘트: "프로펠러 가드를 끼우고, 사람이 없는 구역에서만 날립니다."

### 4-2. 드론의 정의 (1:00~3:30) — 슬라이드 3·4

**① 이름의 유래 (30초)**
- 드론(drone)은 영어로 **'수벌'**, 그리고 **'웅웅거리는 소리'**라는 뜻입니다.
- 1930년대 영국의 무선조종 표적기 **'퀸 비(Queen Bee, 여왕벌)'**에서 영향을 받아, 미국 해군이 무인 표적기를 '드론(수벌)'이라 부르기 시작했다는 이야기가 널리 알려져 있습니다.

**② 드론의 뜻 (1분)**
- 쉬운 정의: **"사람이 타지 않고, 원격 조종이나 스스로 비행할 수 있는 비행체"**
- 법령의 정의: 「드론 활용의 촉진 및 기반조성에 관한 법률」(드론법)에서는 드론을 **"조종자가 탑승하지 아니한 상태로 항행할 수 있는 비행체"**로 정의합니다. 시행규칙은 비행 방식을 세 가지로 나눕니다.

| 방식 | 뜻 | 비유 |
|---|---|---|
| **원격** | 사람이 멀리서 조종 | 리모컨 자동차 |
| **자동** | 미리 입력한 경로대로 비행 | 정해진 길만 가는 기차 |
| **자율** | 비행 환경 변화를 **인식·판단**해 스스로 속도와 경로를 바꿈 | 스스로 판단하는 운전자 → **AI** |

- 영어 용어: **UAV**(Unmanned Aerial Vehicle, 무인항공기)

**③ 드론의 구성 요소 — 이글 드론으로 보기 (1분)**

| 구성 요소 | 하는 일 | 사람에 비유 | 이글 드론 |
|---|---|---|---|
| 프레임·프로펠러 가드 | 몸체와 보호 | 뼈대 | 풀 프로펠러 가드 |
| 모터·프로펠러 | 양력을 만들어 날기 | 날개·근육 | 모터 4개, 75mm 프로펠러 |
| 배터리 | 에너지 공급 | 심장 | 1100mAh, 약 10분 비행 |
| 비행 제어기(FC) | 자세를 계산하고 명령 | **두뇌** | ARM 프로세서 |
| 센서 | 주변을 감지 | **눈·귀·평형감각** | 자이로·기압·레이저 거리·광류 센서 |
| 통신 | 명령 주고받기 | 입과 귀 | 블루투스 5.0 |

- **멘트:** "센서는 눈, 비행 제어기는 두뇌예요. 이 두뇌에 **코드로 생각하는 법**을 넣어 주면, 드론은 스스로 판단할 수 있어요."

### 4-3. 활용 사례 (3:30~6:30) — 슬라이드 5·6

**① 사진 퀴즈 (1분 30초): "이 드론은 무슨 일을 할까?"**
- 사진 3장을 차례로 보여 주고 맞히게 합니다. (심사위원을 학생 삼아 1~2명에게 짧게 질문)
  1. 논 위를 나는 드론 → **농약 방제**
  2. 밤하늘에 그림을 만드는 수백 대의 드론 → **드론 라이트 쇼**
  3. 산속을 나는 열화상 카메라 드론 → **실종자 수색**

**② 6대 활용 분야 정리 (1분 30초)**

| 분야 | 하는 일 | 예시 |
|---|---|---|
| 🌾 농업 | 농약·비료 살포, 작물 생육 관찰 | 방제 드론 |
| 📦 물류 | 섬·산간 지역 배송 | 드론 택배 시범 사업 |
| 🚒 재난·안전 | 실종자 수색, 화재 감시, 구조 물품 전달 | 열화상 수색 드론 |
| 🏗️ 시설 점검 | 교량·송전탑·풍력발전기 점검 | 사람이 가기 위험한 곳 대신 |
| 🎬 촬영·공연 | 방송·영화 촬영, 드론 라이트 쇼 | 대형 행사 개막식 드론 쇼 |
| 🚁 미래 교통 | 사람을 태우는 도심항공교통(UAM) | 하늘을 나는 택시 |

- **멘트:** "공통점은 무엇일까요? **위험하거나, 멀거나, 사람이 하기 힘든 일**을 대신한다는 거예요."

### 4-4. 드론을 배워야 하는 이유 (6:30~9:00) — 슬라이드 7·8

**① 드론은 '조종'에서 '스스로 판단'으로 진화 중 (1분)** — 슬라이드 7
```
 원격 (사람이 조종)  →  자동 (입력한 경로대로)  →  자율 (스스로 인식·판단)
                                                          ↑
                                                    여기에 AI가 필요!
```
- **멘트:** "앞으로의 드론은 사람이 조종하지 않아도 스스로 장애물을 피하고, 사람을 찾고, 길을 정합니다. 이 판단을 만드는 것이 **AI와 코딩**이에요."

**② 드론을 배우면 얻는 것 4가지 (1분 30초)** — 슬라이드 8

| 이유 | 설명 |
|---|---|
| 🧠 **손에 잡히는 AI** | 화면 속 코드가 현실에서 **바로 날아서** 결과를 보여 줌 → 감지·판단·행동을 눈으로 확인 |
| 🔗 **융합 역량** | 코딩 + 과학(양력·센서) + 수학(거리·각도) + 공학(설계)이 한 번에 |
| 💼 **미래 직업** | 드론 SW 개발자, 자율비행 엔지니어, 드론 데이터 분석가, 방제·촬영 전문가, UAM 관련 직업 |
| 🛡️ **책임 있는 사용자** | 비행 규칙, 사생활 보호, 안전 → 드론을 쓰게 될 시민으로서 알아야 할 것 |

- **발문 ②:** "여러분이 드론 개발자라면, 어떤 문제를 해결하는 드론을 만들고 싶나요?" (짧게 1명)

### 4-5. 마무리·본 수업 연결 (9:00~10:00) — 슬라이드 9

- **한 문장 정리:** "드론은 사람이 타지 않는 비행체에서 시작해, 이제는 **스스로 보고 판단하는 하늘의 AI**가 되고 있습니다."
- **연결 멘트:** "오늘 우리는 드론을 리모컨으로 **조종**하지 않습니다. 코딩으로 드론에게 **생각하는 법**을 가르칠 거예요. 이 작은 드론이 앞에 무언가 있으면 스스로 멈추게 만들어 봅시다!"
- (드론을 다시 들어 보이며 마무리)

## 5. 학교급별 조절표

같은 슬라이드를 쓰고, **설명 깊이·예시·발문**만 바꿉니다.

| 구간 | 초등 | 중등 | 고등 |
|---|---|---|---|
| **도입 발문** | "드론을 본 적 있나요? 어디서 봤나요?" | "드론 하면 떠오르는 것은?" | "드론 하면 떠오르는 기술이나 산업은?" |
| **정의** | "사람이 타지 않고 날아다니는 **로봇 비행기**" + 수벌 이야기 | 쉬운 정의 + UAV 용어 + 원격·자동·자율 | **법령 정의** + 원격·자동·자율 + "자율의 조건 = 인식·판단" |
| **구성 요소** | 사람 몸 비유 중심 (눈·두뇌·심장·날개) | 비유 + 각 부품의 역할 | 부품 역할 + 센서 종류(자이로·기압·광류·레이저)가 무엇을 재는지 |
| **활용 사례** | 퀴즈 중심: 택배, 소방, 드론 쇼 | 6대 분야 + "드론이 바꾼 일자리" | 6대 분야 + UAM, 산업 데이터(점검·측량), 국방 → 기술의 양면성 |
| **배워야 하는 이유** | "내가 만든 코드로 드론이 날아요!" 재미 + 꿈 | 융합 역량 + 미래 직업 | 진로·전공 연계(항공우주·컴퓨터·AI·기계), 산업 성장, **규제와 윤리** |
| **마무리 발문** | "드론에게 어떤 일을 시키고 싶나요?" | "어떤 문제를 해결하는 드론을 만들고 싶나요?" | "자율 드론이 잘못 판단하면 누구 책임일까요?" (본 수업 윤리 토론 예고) |
| **시간 조절** | 정의를 짧게(2분), 퀴즈를 길게(2분) | 기본 배분 | 정의와 진로를 길게, 퀴즈는 1분 |

## 6. 슬라이드 구성안 (9장)

| # | 제목 | 핵심 내용 | 시각 자료 | 시간 |
|---|---|---|---|---|
| 1 | **드론, 어디까지 알고 있니?** | 강의 제목, 강사 소개 | 이글 드론 사진 (큰 이미지) | 0:20 |
| 2 | **'드론' 하면 떠오르는 것은?** | 발문 ① | 촬영·택배·드론 쇼 아이콘 흩뿌리기 | 0:40 |
| 3 | **드론이란?** | 수벌 유래 → 쉬운 정의 → 법령 정의, 원격·자동·자율 표 | 수벌 그림, 3단계 아이콘 | 1:30 |
| 4 | **드론의 몸 살펴보기** | 구성 요소 6가지 ↔ 사람 비유 | 이글 드론 분해도에 화살표 라벨 | 1:00 |
| 5 | **퀴즈! 이 드론은 무슨 일을 할까?** | 사진 3장 퀴즈 | 방제·드론 쇼·수색 사진 (클릭하면 정답) | 1:30 |
| 6 | **하늘에서 일하는 드론** | 6대 분야 + 공통점 "위험·멀리·힘든 일" | 6칸 아이콘 그리드 | 1:30 |
| 7 | **조종에서 스스로 판단으로** | 원격 → 자동 → 자율, AI 강조 | 3단계 화살표, 마지막 칸 강조 | 1:00 |
| 8 | **왜 드론을 배워야 할까?** | 손에 잡히는 AI, 융합, 직업, 책임 | 4칸 카드 | 1:30 |
| 9 | **오늘의 미션: 드론에게 생각하는 법을!** | 한 문장 정리 + 본 수업 예고 | 이글 드론 + 감지→판단→행동 다이어그램 | 1:00 |

> 학교급별 슬라이드는 같은 9장을 쓰고, **3·6·8번 슬라이드의 텍스트 양**만 학교급에 맞게 바꾼 버전을 따로 만듭니다.

## 7. 시연 운영 팁

| 상황 | 대응 |
|---|---|
| 시범 비행이 어려운 공간 | 시범 비행은 빼고 **5초짜리 백업 영상**을 슬라이드 2에 삽입 |
| 블루투스 연결 실패 | 연결 시도는 1회만 하고 바로 영상으로 전환 (시간 지키기가 우선) |
| 시간이 부족할 때 | 슬라이드 5 퀴즈를 1장으로 줄이고, 슬라이드 4 구성 요소를 "눈·두뇌·날개" 3개만 설명 |
| 시간이 남을 때 | 슬라이드 8에서 발문 ②를 2명에게 질문 |
| 심사위원 참여 | "학생이라고 생각하고 답해 주세요"로 자연스럽게 요청, 답이 없으면 강사가 예시 답을 말하고 진행 |
